# Ayesha Aziz Laghari — Technical Recruiter Portfolio

This folder contains the complete static website currently used for Ayesha's portfolio.

## Files

- `index.html` — page structure and content
- `styles.css` — colors, layout, responsive design, and illustrations
- `script.js` — lightweight interaction behavior
- `assets/` — Ayesha's photographs, coffee image, and downloadable CV
- `vercel.json` — Vercel configuration

## Replace an existing GitHub repository

1. Download and unzip the supplied package.
2. Open your existing GitHub repository.
3. Delete the old website files that this package replaces. Keep unrelated files only if you know they are still required.
4. Upload everything inside this folder to the repository root—not the enclosing folder itself.
5. Commit the changes to the branch connected to Vercel, usually `main`.
6. Vercel should deploy the new commit automatically.

The repository root should contain `index.html`, `styles.css`, `script.js`, `vercel.json`, and the `assets` folder.

## Local preview

Open `index.html` in a browser, or serve this folder with any static file server.

## Vercel settings

- Framework preset: **Other**
- Build command: leave empty
- Output directory: leave empty or use `.`
- Root directory: repository root
